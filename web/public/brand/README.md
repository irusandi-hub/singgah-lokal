# SINGGAH LOKAL — master brand assets

Letakkan file master logo (dari Brand Identity Guidelines) di folder ini
dengan nama persis:

- `singgah-lokal-logo-horizontal.png` — logo horizontal (header/brand utama)
- `singgah-lokal-logo-mark.png` — logo mark (ruang terbatas/mobile)
- `singgah-lokal-icon-512.png` — app/PWA icon 512px
- `singgah-lokal-favicon.ico` — favicon

File dipakai apa adanya oleh aplikasi (tanpa digambar ulang, tanpa efek,
tanpa perubahan warna/propoti). Selama file belum ada, UI menampilkan
wordmark teks dua-warna sebagai fallback sehingga tidak ada broken image.
